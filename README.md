# iRush ⚡

**iRush** is a fast, 100% free, and open-source USB file transfer tool for copying files directly from a Windows PC to an iPhone over a standard data cable at full hardware wire speeds.

No Wi-Fi, no local network sluggishness, no subscriptions, and no cloud uploads.

---

## Why iRush?

Transferring files to an iPhone from Windows over Wi-Fi apps (like Feem, AirDroid, or web transfer tools) is often frustratingly slow:
- A 400 MB video can take 30 to 45 minutes over crowded Wi-Fi.
- With **iRush over a direct USB cable**, that same 400 MB file transfers in **under 15 seconds** at real physical wire speeds (~25–35 MB/s).

---

## Features

- **⚡ Blazing Fast USB Cable Speed**: Transfers videos, lossless music, and heavy documents in seconds using optimized batch streaming.
- **📁 Clean Categorized Organization**: One permanent **`iRush`** folder on your iPhone, neatly split into subfolders:
  - 🎬 `Videos` (`.mp4`, `.mkv`, `.mov`, `.avi`, `.webm`, `.ts`, etc.)
  - 📄 `Documents` (`.pdf`, `.docx`, `.xlsx`, `.pptx`, `.txt`, `.epub`, etc.)
  - 🎵 `Audio` (`.mp3`, `.m4a`, `.flac`, `.wav`, `.aac`, etc.)
  - 🖼️ `Photos` (`.jpg`, `.png`, `.heic`, `.gif`, etc.)
  - 📦 `Archives` (`.zip`, `.rar`, `.7z`, `.tar`, `.gz`, etc.)
- **🎯 Universal Zero-Config Compatibility**: Automatically detects file-sharing containers on any iPhone in the world (Chrome, VLC, Documents by Readdle, Apple Pages, Acrobat Reader, etc.). No specific app is mandatory!
- **🖱️ Drag & Drop UI**: Minimalist, clean Apple-style interface. Drag a single file or dozens of files simultaneously.
- **📊 Real-time Speed & Progress**: Live speed meter (MB/s), estimated time remaining (ETA), and byte transfer counter.
- **🪟 Clean Windows Launcher**: Launches as a standalone native window with **zero visible Command Prompt box** and shuts down cleanly as soon as you close the window.

## Compatibility

- **iPhone Models**: Compatible with all iPhone models from **iPhone X** up to **iPhone 16 / 18 Pro Max**.
- **iOS Versions**: iOS 13 through iOS 18+.
- **Operating System**: Windows 10 and Windows 11 (64-bit).

---

## How to Access Your Transferred Files on iPhone

On iOS, files are safely placed into your device's storage:
1. Open the built-in **Files** app on your iPhone.
2. Tap **Browse** ➔ **On My iPhone**.
3. Tap your container (e.g., **Chrome** or **VLC**).
4. Open the **`iRush`** folder:
   ```
   On My iPhone
   └── Chrome (or VLC / Documents)
       └── iRush
           ├── Videos
           ├── Documents
           ├── Audio
           └── Photos
   ```
5. **Move to Downloads / iCloud**: Tap and hold any file or folder and tap **Move** to put it in your Safari Downloads, iCloud Drive, or anywhere you like with a single tap.

## Prerequisites for Windows

1. **Node.js** (v18 or higher): [Download from nodejs.org](https://nodejs.org/)
2. **Apple Mobile Device Support**: Installed automatically if you have **iTunes for Windows** or the official **Apple Devices** app from the Microsoft Store.
3. A standard Apple Lightning or USB-C data cable.

---

## Quick Start (Running iRush)

1. Download or clone this repository (Click **Code ➔ Download ZIP** and extract it).
2. Double-click **`iRush.exe`**.
   - *On the very first launch, it will automatically install required dependencies in a few seconds.*
3. Plug your iPhone into your PC via USB cable.
   - Unlock your iPhone and tap **"Trust This Computer"** if prompted.
4. Drag and drop any files into the iRush window to transfer!
