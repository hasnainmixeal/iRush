# Contributing to iRush ⚡

Thank you for your interest in contributing to **iRush**! We welcome community contributions to help improve high-speed USB data transfers for iOS users worldwide.

## How to Contribute

### Reporting Bugs
If you find a bug:
1. Open an Issue on GitHub with a descriptive title.
2. Include your:
   - Windows OS version (e.g. Windows 11 23H2)
   - iPhone model and iOS version (e.g. iPhone 12, iOS 18.1)
   - Cable type (Lightning or USB-C)
   - Relevant terminal output or error description.

### Suggesting Enhancements
Feature requests are welcome! Please open an issue explaining the proposed feature and why it would be beneficial.

### Pull Requests
1. Fork the repository.
2. Create your feature branch (`git checkout -b feature/amazing-feature`).
3. Commit your changes (`git commit -m "Add amazing feature"`).
4. Push to the branch (`git push origin feature/amazing-feature`).
5. Open a Pull Request.

## Code Guidelines
- Keep code clean, modular, and dependency-light.
- Ensure all native USB socket communication maintains buffer batching for throughput.
- Keep the UI responsive, minimalist, and Apple-inspired.
